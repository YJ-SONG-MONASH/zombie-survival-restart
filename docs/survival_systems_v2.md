# 生存系统 v2

## 核心循环

玩家在地图节点间迁移，并在有限时间内完成搜刮、侦察、休整、睡眠、觅食、战斗、制作与据点维护。所有行动以分钟结算：生理需求随时间增长，天气、水电、噪声、尸群压力与伤口也在同一模拟时钟上推进。

```text
评估地点与尸群
  -> 选择潜行 / 近战 / 枪械 / 搜刮
  -> 结算耗时、噪声、物资与伤口
  -> 主动进食、治疗、制作或迁移
  -> 熬过停水停电和尸群事件
  -> 第 20–25 天抵达撤离节点
```

## 状态所有权

- `src/services/survival.js`：纯生存模拟。负责时钟、天气、水电、噪声、尸群压力、伤口进展、战斗和 Moodle（状态提示）。
- `src/services/engine.js`：把地图行动转换成一次结算结果，不直接持有 Vue 状态。
- `src/stores/game.js`：唯一可保存的游戏状态和命令入口，负责存档迁移、库存原子变更、结算应用和终局状态机。
- `src/views/SurvivalView.vue`：展示和输入。地点搜索只在组件内暂存，确认结算后才一次性提交到 store，刷新不会复制物资。

## 失败与胜利

- 生命归零或 Knox 感染达到 100%：立即失败。
- 第 20 天起开放撤离；在第 25 天结束前抵达 `valley_checkpoint` 或 `louisville_outskirts`：胜利。
- 第 25 天后仍未抵达撤离点：错过撤离窗口。

## 可扩展边界

下一阶段应优先沿现有状态边界扩展，而不是把规则重新放回 Vue：

1. 分离随身背包、车辆后备箱和据点仓库。
2. 为技能增加经验与等级成长，并把武器耐久、食物腐败接入小时制。
3. 将 NPC 卡升级为关系、交易、任务与小队成员系统。
4. 为随机源增加可保存 seed 与调用序列，使整局可复盘。
5. 在不破坏单机 reducer 的前提下增加服务端权威房间制联机。
