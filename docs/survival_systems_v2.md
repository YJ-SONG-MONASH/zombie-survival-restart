# 生存系统 v2

## 核心循环

玩家在地图节点间迁移，并在有限时间内完成搜刮、侦察、休整、睡眠、觅食、战斗、制作与据点维护。所有行动以分钟结算：生理需求随时间增长，天气、水电、噪声、尸群压力与伤口也在同一模拟时钟上推进。

```text
评估地点与尸群
  -> 遭遇时进入距离分层的战术回合
  -> 推开 / 踩踏 / 后撤 / 瞄准 / 装填 / 开火 / 脱离
  -> 每回合原子结算耗时、噪声、弹药、耐久、尸群与伤口
  -> 主动进食、治疗、制作或迁移
  -> 熬过停水停电和尸群事件
  -> 第 20–25 天抵达撤离节点
```

## 状态所有权

- `src/services/survival.js`：纯生存模拟。负责时钟、天气、水电、噪声、尸群压力、伤口进展和 Moodle（状态提示）；旧聚合战斗函数仅供历史回归，Store 的战斗入口全部委托新战术状态机。
- `src/services/tactical-encounter.js`：纯战术状态机。负责回合随机游标、距离/抓取/倒地、行动预览及精确物品 effects，不直接修改 Store。
- `src/services/engine.js`：把地图行动转换成一次结算结果，不直接持有 Vue 状态。
- `src/stores/game.js`：唯一可保存的游戏状态和命令入口，负责存档迁移、战术命令防重放、精确弹药/武器事务、结算应用和终局状态机。
- `src/views/SurvivalView.vue`：展示和输入。战术界面只消费 Store 的行动预览并发送命令，不在 Vue 中重算命中与风险；地点搜索仍在组件内暂存，确认后一次性提交。

## 失败与胜利

- 生命归零或 Knox 感染达到 100%：立即失败。
- 第 20 天起开放撤离；在第 25 天结束前抵达 `valley_checkpoint` 或 `louisville_outskirts`：胜利。
- 第 25 天后仍未抵达撤离点：错过撤离窗口。

## 可扩展边界

下一阶段应优先沿现有状态边界扩展，而不是把规则重新放回 Vue：

1. 把地点战利品升级为带父场景稳定键的持久化世界容器，让未带走物资留在原地并支持往返搬运。
2. 将烹饪、耕种、钓鱼与基地生产接入已有的腐败、时间和仓储循环。
3. 将 NPC 卡升级为关系、交易、任务与小队成员系统。
4. 扩展可复盘随机源到地点搜索和世界事件，并增加最近有效存档回退。
5. 在不破坏单机纯规则层的前提下增加服务端权威房间制联机。
