# 僵尸毁灭工程模拟器二创计划

## 基础结论

- 基底仓库：VickScarlet/lifeRestart
- 本地路径：G:\Projects\Projects\僵尸毁灭工程模拟器
- 许可证：MIT。二创、修改、发布允许，但必须保留原版权与 MIT 许可证声明。
- 当前技术栈：Vite + LayaAir + 原生 JavaScript 模块。
- 核心玩法：抽取天赋、分配属性、逐年龄推进事件、结算总结。

## 可复用部分

- `src/modules/life.js`：游戏主流程，负责初始化、开局、下一阶段推进、事件和天赋触发。
- `src/modules/property.js`：属性系统，负责属性变化、历史最高/最低、结算评级。
- `src/modules/talent.js`：天赋抽取、冲突、替换、触发。
- `src/modules/event.js`：事件读取、条件判断、效果执行。
- `src/functions/condition.js`：事件和成就条件表达式解析。
- `src/ui/themes/*`：现有 LayaAir 页面和主题，可先改文案与配色，后续再重做界面。
- `data/zh-cn/*.xlsx`：内容配置入口，可替换为丧尸生存主题数据。

## 改造目标

把“人生重开模拟器”改造成一个离线可玩的丧尸末世文字生存模拟器。玩家不是从出生长大，而是在末日爆发后按天推进，靠职业、特质、物资和随机事件决定能否活下去。

## 首版玩法设计

### 流程

1. 开始页：进入“僵尸毁灭工程模拟器”。
2. 特质抽取：用原天赋系统改成“幸存者特质”。
3. 初始配置：用原属性分配改成“体能、智识、战斗、物资、心态”。
4. 生存推进：用原年龄推进改成“第 N 天”。
5. 每日事件：触发搜刮、尸潮、感染、避难所、人类冲突、天气、电力和水源事件。
6. 总结页：输出存活天数、死因、幸存者评级、关键事件。

### 属性映射

| 原属性 | 新含义 | 说明 |
| --- | --- | --- |
| AGE | DAY | 生存天数，保留内部字段名，界面显示为天数 |
| CHR | AGI | 敏捷/潜行，影响逃跑、搜刮、躲避尸群 |
| INT | INT | 智识/维修，影响制作、用药、判断陷阱 |
| STR | STR | 体能/战斗，影响近战、防御、搬运 |
| MNY | SUP | 物资，影响开局物资和事件缓冲 |
| SPR | SAN | 心态/理智，低时触发崩溃、失误 |
| LIF | LIFE | 生存状态，0 或负数死亡 |

### 内容分层

- `talents.xlsx` -> 幸存者特质：警校训练、慢跑习惯、园艺经验、烟瘾、易恐慌、厚衣服、药品常识等。
- `events.xlsx` -> 每日事件：第一天爆发、便利店搜刮、夜间尸群、发烧感染、停水停电、邻居求救、雨夜转移等。
- `age.xlsx` -> 每天事件池：第 0 天到第 60 天，前期教学，中期资源压力，后期大规模尸潮和撤离线。
- `achievement.xlsx` -> 成就：活过 7 天、第一次击杀、零感染通关、物资耗尽、精神崩溃等。
- `character.xlsx` -> 预设幸存者：警察、护士、程序员、厨师、运动员、维修工、学生等。

## 实施阶段

### 阶段 1：最小可玩换皮

- 保留 LifeRestart 引擎和 LayaAir UI。
- 改标题、按钮、属性文案、总结文案。
- 建立一套最小丧尸主题数据：20-30 个特质、80-120 个事件、30 天事件池、10 个成就。
- 验证本地可以启动、抽特质、推进天数、死亡和总结。

### 阶段 2：规则增强

- 增加感染、饥饿、口渴、疲劳等派生状态。
- 扩展事件效果，让资源压力比原版人生事件更明显。
- 加入避难所和背包概念。如果直接改原属性模型成本过高，先把它们编码为事件标签或隐藏属性。

### 阶段 3：界面重做

- 从“人生重开”界面改为末世终端风格。
- 优先改移动端体验：状态面板、事件日志、下一天按钮、总结页。
- 旧 Laya 资源可临时保留，后续替换背景、按钮和图标。

### 阶段 4：可发布版本

- 保留 `LICENSE` 并在 README 中注明基于 LifeRestart 二创。
