# 末世模拟器

一个以 Knox Event 为背景、受《Project Zomboid》生存循环启发的非官方网页文字 Roguelike。当前版本已经移除原 LifeRestart/Laya 引擎，改为 Vite + Vue + Pinia + Vue Router。

## 当前玩法

- 首页选择末日场景，目前开放“丧尸围城”。
- 创建幸存者：起名、选择出生点、自由选择职业。
- 默认出生点参考 Build 41：马尔德劳、河畔镇、罗斯伍德、西点。
- 职业和特性按 Project Zomboid Build 41 风格整理。
- 特殊姓名可触发隐藏职业，例如“黑哥 / 刘太荣”和“师一钒 / 师哥”。
- 三次随机抽取避难所，从当前 3 个候选据点中选择后再采购物资。
- 进入小时制生存循环；移动、搜刮、侦察、睡眠、战斗和制作都有不同耗时，不再“一次点击推进一天”。
- 管理生命、耐力、饥饿、口渴、疲劳、恐慌、压力、背包、疼痛、伤口和感染。
- 世界会变化：昼夜、晴雨雾与寒潮会影响行动，市政水电会在不同日期中断，第 9 天直升机事件会推动尸群迁移。
- 每个地图节点都有持久化的本地尸群。遭遇时可以潜行绕过、分批近战清理或消耗匹配弹药枪械突围；清场区域仍可能在后续日期被游荡尸群重新占据。
- 抓伤、撕裂伤和咬伤会流血或感染；绷带会随时间变脏，需要更换或消毒。止痛药和抗生素都有实际用途，但 Knox 感染不能被普通抗生素治愈。
- 支持主动进食/饮水、装备武器、野外觅食、配方制作、据点路障、雨水储备和发电机供电。
- 角色拥有 Build 41 风格技能等级，包括力量、体能、潜行、战斗、制作、枪械和求生技能；移动、搜索、战斗、制作与治疗会获得对应经验并实际升级。
- 采购页提供 60 余种主要生存物资，并按获取风险显示白/绿/蓝/紫/金/红品质。
- 地图行动会预览耗时、所需工具与主要风险，并在结算后展示状态、物资和世界压力变化。
- 第 20–25 天是撤离窗口；必须抵达谷地检查点或路易斯维尔外环，并清场或成功绕过当地尸群才能获胜，原地苟活会错过撤离。
- 结局可保存到本地末世档案馆。
- 存档带版本迁移与异常值清理；首页可以继续当前进度，新游戏会先请求确认。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

构建产物输出到 `template/public`，GitHub Pages 工作流会自动发布。

## 测试与质量门

```bash
pnpm test
pnpm check
```

`pnpm test` 运行核心模拟、战斗/伤口、存档迁移、库存边界与数据完整性测试；`pnpm check` 会继续执行生产构建。GitHub Pages 工作流在发布前也会先运行测试。

## 说明

当前版本使用本地规则引擎，不需要后端。自定义 LLM 叙事尚未接入实际判定，因此首页入口暂时禁用，避免让玩家误以为 API 会改变当前游戏。

`public/pz-traits/` 支持本地私有特性图标，`public/pz-occupations/` 支持本地私有职业图标。
`public/pz-items/` 用于物资图标，并会随构建部署；`public/pz-skills/` 用于本地私有技能图标，PNG 文件会被 `.gitignore` 忽略。缺图时会显示卡片 fallback。

本项目是非官方粉丝作品，与 The Indie Stone 无隶属关系。若公开发布，请只使用拥有授权或可再分发许可的素材。
